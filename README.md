# Equity Performance Analysis and Time-Series Forecasting with LSTM

A time-series data analysis and deep learning project focused on analyzing the historical performance of **Apple, Google, Microsoft, and Amazon**, assessing investment risk, and forecasting Apple stock prices using an **LSTM neural network**.

## Project Highlights

* Retrieved historical stock-market data using Yahoo Finance
* Analyzed closing prices, trading volume, moving averages, and daily returns
* Examined return and price correlations across major technology stocks
* Assessed investment risk using expected returns and volatility
* Built an **LSTM-based time-series forecasting model** for Apple stock prices
* Applied MinMax scaling and 60-day sequential windows for model training
* Evaluated predictions using **Root Mean Squared Error (RMSE)**
* Visualized actual vs. predicted stock-price movements

## Tech Stack

`Python` • `Pandas` • `NumPy` • `Yahoo Finance` • `Matplotlib` • `Seaborn` • `Scikit-learn` • `TensorFlow/Keras` • `LSTM`

## Skills Demonstrated

**Time-Series Analysis • Financial Data Analysis • Risk Analysis • Deep Learning • LSTM Forecasting • Data Visualization • Feature Scaling • Correlation Analysis • Model Evaluation**

## Outcome

Developed an end-to-end financial analytics workflow combining **market trend analysis, portfolio-risk insights, and deep-learning-based stock price forecasting**.
